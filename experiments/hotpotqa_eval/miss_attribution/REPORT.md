## Method

- Routed documents: `selected_titles` in `results.jsonl`. The router returns exactly two titles
  and logs no scores or ranking.
- Gold titles: the oracle prompt headers in `calls.jsonl` (d50 only) and the local dataset
  cache `corpus_cache/hotpotqa_validation_0_100.json`. The two agree on all 50 d50 questions.
- Consistency: recall recomputed from gold titles equals the logged `route_gold_recall` on all
  100 route records, and `hotpotqa_scoring.f1` reproduces every logged F1.
- The script reproduces the existing reports: both gold routed 30/50 (d50) and 29/50 (seed0);
  route F1 0.701 and 0.637; oracle F1 0.839; oracle - full +0.170, CI [+0.072, +0.276].
- Classes, from the route arm: (a) both gold routed and correct (EM = 1); (b) both routed,
  wrong (answer miss); (c) one gold routed; (d) no gold routed (routing miss).

## 1. Miss attribution

| Class | seed0 n / route F1 | d50 n / route F1 | d50 oracle F1 |
| :-- | --: | --: | --: |
| a: both routed, correct | 19 / 1.000 | 22 / 1.000 | 0.985 |
| b: both routed, wrong | 10 / 0.302 | 8 / 0.271 | 0.433 |
| c: one routed | 15 / 0.603 | 18 / 0.560 | 0.823 |
| d: none routed | 6 / 0.133 | 2 / 0.400 | 1.000 |

Two of the seed0 class-d questions are unparsable routing replies (F1 0, no answer call).

Gap decomposition on d50 (each cell is the class's summed per-question difference divided by 50):

| Gap | total | a | b | c | d |
| :-- | --: | --: | --: | --: | --: |
| oracle - full | +0.170 | +0.044 | +0.027 | +0.084 | +0.014 |
| oracle - route | +0.138 | -0.007 | +0.026 | +0.095 | +0.024 |

Of the oracle - route gap, routing misses (c + d) account for +0.119 and answer misses (b) for
+0.026. seed0 has no oracle arm; its full - route gap (+0.077, CI [-0.040, +0.198]) splits as
c + d +0.070, b +0.031, a -0.024.

Routing recall, not answering, is where most of the recoverable F1 sits on this data.

## 2. Fetch-more replay

Rules that need router scores (top-k expansion, low-margin triggers) cannot be replayed: no
scores or rankings are logged. Seventeen score-free title-link rules were replayed: add
unrouted documents whose titles the routed documents mention (forward) or that mention a routed
title (both directions). A selection criterion was fixed in code before looking at the results:
the most both-gold questions on d50 with at most 1.0 extra document per question on average;
ties go to fewer extra documents.

**Frozen candidate: `link1-both`.** Add the single best title-linked unrouted document,
forward links first.

| Run | Both gold | Mean gold recall | Triggered | Extra docs | Extra prompt tokens (est.) |
| :-- | :-- | :-- | --: | --: | --: |
| d50 | 30 -> 40/50 | 0.780 -> 0.890 | 35/50 | 0.70 | ~93 |
| seed0 | 29 -> 36/50 | 0.730 -> 0.820 | 32/50 | 0.64 | ~95 |

One random extra document gives 30.3/50 on d50 in expectation. The runner-up `link1-forward`
reached 39/50 with 0.48 extra documents, so the choice between them rests on one question.

## Limitations

- n = 50, one model. seed0 and d50 use the same 50 questions, so seed0 is not an independent check.
- The rule was chosen from 17 variants on this development data; its recall gain is optimistic.
- Recall is not F1. The 8 class-b questions show that routing both gold documents does not
  guarantee a correct answer. No F1 effect is claimed.
- Title matching is a string heuristic (whole-word, disambiguator stripped).
- Future routing runs should log router scores or rankings so score-based rules can be tested.
